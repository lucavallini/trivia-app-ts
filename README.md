# Trivia Game App

Aplicación web interactiva desarrollada utilizando HTML, CSS, JavaScript y TypeScript, basada en un sistema de preguntas y respuestas consumidas desde una API de trivia.

El proyecto fue migrado desde una versión inicial desarrollada en JavaScript hacia TypeScript con el objetivo de mejorar la organización, tipado y escalabilidad del código.

La aplicación utiliza LocalStorage para almacenar datos localmente y Web Components para crear componentes reutilizables dentro de la interfaz.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- TypeScript
- Web Components
- Fetch API
- LocalStorage

## Funcionalidades

- Consumo de API de trivia mediante Fetch API
- Sistema dinámico de preguntas y respuestas
- Almacenamiento local utilizando LocalStorage
- Componentes reutilizables mediante Web Components
- Migración de JavaScript a TypeScript
- Diseño responsive utilizando Flexbox
- Interfaz interactiva y dinámica

## Objetivo del proyecto

Este proyecto fue desarrollado con fines de práctica para aplicar conceptos de:
- consumo de APIs REST,
- migración y tipado con TypeScript,
- manipulación del DOM,
- almacenamiento local,
- desarrollo de componentes reutilizables,
- y construcción de interfaces web dinámicas utilizando tecnologías frontend modernas.
